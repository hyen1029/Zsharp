# 构建与发布

本文档说明如何从源码跑起来、打包成绿色版、再压成安装包。

---

## 1. 环境准备

| 依赖 | 版本 | 说明 |
|---|---|---|
| Windows | 10 / 11，64 位 | Vulkan 运行时由显卡驱动提供 |
| Python | **3.9 ~ 3.11，64 位** | 3.12+ 与 PyQt5 5.15 存在兼容问题，不建议 |
| Git | 任意较新版本 | https://git-scm.com/download/win |
| Inno Setup | 6.x | 仅打安装包时需要，https://jrsoftware.org/isdl.php |

```powershell
git clone https://github.com/hyen1029/Zsharp.git
cd Zsharp
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

---

## 2. 准备 `bin/` 运行时依赖

`bin/` **不进仓库**（体积约 760 MB）。程序通过 `bin/` 下的可执行文件完成推理与编解码，
缺任何一个都会导致对应功能不可用。

推荐目录结构：

```
bin/
├── ffmpeg/         ffmpeg.exe  (+ LICENSE、COPYING.GPLv*)
├── realesrgan/     realesrgan-ncnn-vulkan.exe  + models/
├── realcugan/      realcugan-ncnn-vulkan.exe   + models-se/ models-pro/
├── realsr/         realsr-ncnn-vulkan.exe      + models-DF2K/ models-DF2K_JPEG/
├── waifu2x/        waifu2x-ncnn-vulkan.exe     + models-cunet/ 等
├── rife/           rife-ncnn-vulkan.exe        + rife-anime/ rife-v4.6/
├── vlc/            libvlc.dll + plugins/       （可选，视频预览）
├── mpv/            mpv.exe                     （可选）
└── mpvlib/         libmpv-2.dll                （可选）
```

上游获取地址：

| 组件 | 地址 |
|---|---|
| FFmpeg | https://github.com/GyanD/codexffmpeg/releases |
| Real-ESRGAN ncnn | https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan/releases |
| Real-CUGAN ncnn | https://github.com/nihui/realcugan-ncnn-vulkan/releases |
| RealSR ncnn | https://github.com/nihui/realsr-ncnn-vulkan/releases |
| waifu2x ncnn | https://github.com/nihui/waifu2x-ncnn-vulkan/releases |
| RIFE ncnn | https://github.com/nihui/rife-ncnn-vulkan/releases |
| VLC | https://www.videolan.org/vlc/download-windows.html |

> 程序用 `find_exe()` 在 `bin/` 下**递归**搜索可执行文件名，所以子目录叫什么不重要，
> 但**每个 exe 必须和它的 `models/` 目录放在一起**，否则引擎找不到权重。

准备好后可先跑一遍源码验证：

```powershell
python app_qt.py
```

## 3. 打包绿色版

```powershell
# 若提示「禁止运行脚本」，先放开当前会话的执行策略：
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force

.\build\build.ps1
```

脚本会调用 PyInstaller 按 `build/Zsharp.spec` 生成 `dist/Zsharp/`，然后把
`bin/`、`icon.png`、`ic_*.png` 复制进去，最终产物结构：

```
dist/Zsharp/
├── Zsharp.exe
├── _internal/            PyQt5、Python 运行时
├── bin/                  推理引擎与模型
├── icon.png
└── ic_*.png
```

### 可选预览组件

`bin/mpv/`（122 MB）和 `bin/vlc/`（136 MB）只用于视频预览，**官方发行版默认不打包**，
这样安装包能从约 580 MB 压到约 319 MB。程序在缺少它们时会自动跳过预览。

需要带上它们时：

```powershell
.\build\build.ps1 -WithPreview
```

手动执行等价命令：

```powershell
pyinstaller build/Zsharp.spec --noconfirm --clean
```

> 必须是 `onedir` 模式（不是 `onefile`）。程序需要在 exe 同级目录读写 `bin/`、
> `output/` 和 `settings.json`，`onefile` 的临时解压目录会导致路径错乱。

## 4. 打包安装包

1. 用 Inno Setup 打开 `installer/setup.iss`
2. 确认 `Source` 指向 `dist/Zsharp/`
3. 修改 `AppVer` 为本次版本号
4. `Build → Compile`，产物为 `Zsharp-Setup.exe`

命令行编译：

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\setup.iss
```

安装包特性：安装到 `%LOCALAPPDATA%\Programs\Zsharp`，**无需管理员权限**，
可选桌面快捷方式，支持干净卸载。

## 5. 版本号

版本号出现在**两个地方**，发布前必须同步：

| 位置 | 变量 | 作用 |
|---|---|---|
| `app_qt.py` 第 14 行 | `APP_VERSION = "x.y.z"` | 程序内显示、更新检查比对 |
| `installer/setup.iss` 第 2 行 | `#define AppVer "x.y.z"` | 安装包版本、控制面板显示 |

> ⚠️ 当前仓库这两个值不一致：`app_qt.py` 是 `1.2.0`，`setup.iss` 是 `1.5.1`。
> 发布前请统一，并重新打包，否则「设置 → 通用」里显示的版本号会和安装包不符。

## 6. 发布检查清单

- [ ] `APP_VERSION` 与 `AppVer` 已同步
- [ ] `CHANGELOG.md` 已添加本次条目
- [ ] `bin/` 下各引擎的 `LICENSE` 均在包内
- [ ] FFmpeg 源码获取方式已在 `THIRD_PARTY.md` / 发行说明中给出
- [ ] 绿色版在**干净机器**上解压即用（不依赖开发机的 Python）
- [ ] 安装包在干净机器上可安装、可卸载、无残留
- [ ] 用 NVIDIA / AMD / Intel 三种显卡各验证一次编码路径
- [ ] 生成 SHA256 校验值并附在 Release 里

```powershell
Get-FileHash .\Zsharp-Setup.exe -Algorithm SHA256 | Format-List
Get-FileHash .\Zsharp-1.5.1-win64.zip -Algorithm SHA256 | Format-List
```

## 7. 常见打包问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 双击 exe 闪退 | 缺 `_internal` 目录 | 确认是 `onedir` 产物，整个目录一起分发 |
| 界面正常但超分报错 | `bin/` 未复制或引擎缺 models | 检查 `dist/Zsharp/bin/` 下每个引擎目录 |
| 启动报 `VCRUNTIME140.dll` 缺失 | 系统缺 VC++ 运行库 | 安装 [VC++ 2015-2022 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe) |
| 杀软误报 | PyInstaller 打包程序常见 | 考虑代码签名；至少提示用户添加信任 |
| 安装包体积过大 | `bin/` 含全部模型 | 正常，LZMA2 已压到约 335 MB |
