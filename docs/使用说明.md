# Zsharp 使用说明

## 功能

图片、视频本地超分（2× / 3× / 4×），**全程离线，不联网、不上传**。

两个独立工作区：

| 工作区 | 支持格式 |
|---|---|
| 图片超分 | `png` `jpg` `jpeg` `bmp` `tif` `tiff` `webp` |
| 视频超分 | `mp4` `mkv` `avi` `mov` `wmv` `flv` `m4v` `ts` `webm` |

视频工作区会自动「抽帧 → 逐帧增强 → 合成」，并**保留原音轨**。

---

## 添加文件

- 直接把文件或**整个文件夹**拖进窗口即可（文件夹会递归扫描）
- 也可以点「添加」按钮选择
- 拖图片会自动切到「图片超分」页，拖视频自动切到「视频超分」页

---

## 四套引擎、10 个模型

### Real-ESRGAN

| 模型 | 适合 | 倍率 |
|---|---|---|
| 动漫 / 视频 · 快速 | 二次元、CG、游戏截图、视频首选 | 2× / 3× / 4× |
| 动漫 · 高质量 | 线条更干净，比快速慢约 3 倍 | 4× |
| 真人 / 实拍 / 风景 | 真实照片专用 | 4× |

### Real-CUGAN

| 模型 | 适合 | 倍率 | 降噪 |
|---|---|---|---|
| 动漫 · 均衡（SE） | 细节与降噪平衡 | 2× / 3× / 4× | -1 ~ 3 |
| 动漫 · 强力（Pro） | 修得狠，适合压缩痕迹重的老图老番 | 2× / 3× | -1 / 0 / 3 |

### RealSR

| 模型 | 适合 | 倍率 |
|---|---|---|
| 真人 / 实拍 · 高保真（DF2K） | 实拍最稳，不油腻 | 4× |
| 真人 / 实拍 · 去 JPEG 脏边 | 压烂的网图先用它 | 4× |

### waifu2x

| 模型 | 适合 | 倍率 | 降噪 |
|---|---|---|---|
| 动漫 · 降噪（CUNet） | 老动画、包浆图 | 1× / 2× | 0 ~ 3 |
| 动漫 · 快速（Upconv） | 追求速度 | 1× / 2× | 0 ~ 3 |
| 真人 · 快速（Photo） | 真人照片的轻量选择 | 1× / 2× | 0 ~ 3 |

## 操作流程

1. 双击 `Zsharp.exe`
2. 切到「图片超分」或「视频超分」
3. 把文件拖进窗口，或点「添加」
4. 左侧选模型和倍数，需要时调「画面调整」
5. 点右下「开始处理」
6. 结果在各标签页的输出目录，文件名带 `_2x` / `_4x`

处理过程中可以随时暂停或中止。界面上的「原素材 / 超分后 / 左右对比」三个视图可切换，
对比模式下中间分割线可以拖动。

## 画面调整

超分模型的输出有时会偏灰、偏闷，这一组参数就是用来找回来的：

| 参数 | 默认值 | 调整建议 |
|---|---|---|
| 对比度 | 1.06 | 嫌灰就加到 1.10 ~ 1.15 |
| 饱和度 | 1.08 | 画面发闷就加 |
| 锐化 | 0.60 | 模糊重就加到 0.8 ~ 1.0；噪点多就降到 0.3 |
| 亮度 | 0 | 一般不用动 |

这组参数图片和视频都生效，视频在编码时一并处理，**不会多跑一遍**。
调完点「恢复默认」一键还原。

---

## 视频补帧

视频页可额外开启补帧：

| 选项 | 说明 |
|---|---|
| 关闭 | 保持原帧率 |
| 光流（ffmpeg） | 通用，速度快，运动复杂时可能有果冻感 |
| RIFE（AI 动漫） | `rife-anime` 模型，适合动画 |
| RIFE（AI 通用） | `rife-v4.6` 模型，适合实拍 |

补帧与超分叠加会显著增加耗时，建议先用短视频测试。

## 参数建议

| 素材 | 推荐 |
|---|---|
| 动漫 / 游戏 CG | Real-ESRGAN 快速，或 Real-CUGAN 均衡 |
| 老番、压缩痕迹重 | Real-CUGAN Pro（降噪 3） |
| 真人照片 | Real-ESRGAN「真人 / 实拍」，或 waifu2x Photo |
| 实拍视频 | RealSR（DF2K） |
| 只降噪不放大 | waifu2x，倍数设 1 |
| 视频 | 先 2 倍，4 倍约需 3 倍时间 |

## 编码设置

程序会自动识别显卡厂商并预选编码器：

| 编码器 | 适用 |
|---|---|
| CPU · libx264 | 最稳，通用，速度慢 |
| NVIDIA · NVENC | N 卡硬件编码 |
| AMD · AMF | A 卡硬件编码 |
| Intel · QSV | 核显硬件编码 |

硬件编码失败时会自动回落到 `libx264`。
预设（preset）可在「设置 → 性能」中调整。

---

## 性能参考

测试环境：AMD RX 7650 GRE，Windows 11。

| 任务 | 耗时 |
|---|---|
| 图片 1080p → 4×（Real-ESRGAN 快速） | 约 2 秒 |
| 视频 640×480 → 2×（7.5 秒片段） | 约 15 秒 |
| 视频 1080p → 2× | 约「时长 × 2 ~ 4」 |

视频流程为「拆帧 → 逐帧增强 → 合成」，处理前请留出约
**「视频体积 ×10」** 的临时空间，结束后会自动清理。

## 常见问题

| 现象 | 处理 |
|---|---|
| 处理到一半报错 | 切块改 256；视频先换 2 倍 |
| 视频没有声音 | 默认保留原音轨，个别编码需先转 AAC |
| 画面偏「塑料」 | 换模型，或把倍数降到 2 |
| 画面发灰 | 对比度调到 1.10 以上，锐化 0.6 左右 |
| 拖进去没反应 | 确认扩展名在支持列表里；文件夹会递归扫描 |
| 提示找不到引擎 | `bin/` 目录缺失或被移动，重新解压完整包 |

## 设置项

「设置」窗口分三个标签页：

- **外观**：主色（accent）、背景图、背景模糊半径、背景压暗程度
- **性能**：视频编码器、编码预设
- **通用**：版本号、更新检查

所有设置保存在程序目录下的 `settings.json`，删除该文件即可恢复默认。
